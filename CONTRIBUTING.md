# Contributing to Awesome SaaS Comparison Data

Thanks for your interest in improving this dataset! Here's how you can help:

## 🐛 Report Data Errors

If you notice incorrect pricing, wrong URLs, or outdated information:

1. Open an [Issue](../../issues/new)
2. Include the tool name, what's wrong, and what the correct data should be
3. Provide a source link if possible

## 🆕 Suggest New Tools

We prioritize tools that are:
- Actively maintained with a public pricing page
- Used by 1,000+ teams or individuals
- In one of our [28 tracked categories](https://comparedge.com/best)

To suggest a tool:
1. Open an [Issue](../../issues/new) with the title: `[New Tool] Tool Name`
2. Include: name, website, category, pricing page URL

## 📊 Data Quality Standards

All data in this repository follows these rules:
- **No fake or estimated ratings** — only verified data
- **Pricing must be from official sources** — no third-party estimates
- **Free plan data must be current** — verified within the last 90 days

## ⚠️ What We Don't Accept

- Pull requests that modify data files directly (data is generated from our main database)
- Tools with no public pricing information
- Defunct or discontinued products

## 📧 Contact

For bulk data inquiries or partnership proposals, reach us through [comparedge.com](https://comparedge.com).
